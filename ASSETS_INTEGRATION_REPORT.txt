4) PRICING LOGIC (source mai sirf advance tha)
--------------------------------------------------------------------------------
Source field: advanceAmount (rupees)
Store rule   : 6-month plan ka advance = 25% of cash price
Derivation   : cashPriceRs = advanceAmount × 4

Is formula ka faida:
  - Card par jo "advance" dikhta hai wo bilkul source value ke barabar hai.
    Example: Infinix Hot 60i source advance Rs 6,900 → cash Rs 27,600 →
    plan 6 advance = Rs 6,900 (verified 50/50 products).
  - Existing `plansFor()` engine se 3 plans banti hain:
        6 months  → 25% advance, 14% total markup
        12 months → 30% advance, 22% total markup
        18 months → 35% advance, 30% total markup
  - Sab amounts integer paisa mai store hoti hain (project ka money rule).

Note: source advance amounts kuch rows mai noisy hain (e.g. budget phone
Rs 27,900 advance), is liye derived cash price kuch products mai market se high
ya low lag sakta hai. Ye source data ki limitation hai; formula har product par
consistent hai aur installment math ko valid rakhta hai.

11) IMAGE PIPELINE FIX + CLOUDINARY (2026-10-17, follow-up)

User report: website par kisi bhi product ki image show nahi ho rahi thi.

11.1 Root cause (do problems thin)
    a) `assets/images` ki saari 1,130 files invalid HTML 404 pages thin (already
       documented in section 10).
    b) Purane scraper ne image URL ka base galat banaya tha:
         galat : https://www.qistbazaar.pk/images/<file>          → 404
         sahi  : https://backend.qistbazaar.pk/public/images/<file> → 200
       Is liye assets mai images kabhi download hi nahi hui thin.

11.2 Fix — real source images + Cloudinary
    Naya script: `server/src/seed/sync-images.ts`
    Run: `npm run sync:images`

    Script kya karta hai:
      1. Live product sitemap (1,154 URLs) fetch karta hai.
      2. Har imported product ko brand + model code + category ke basis par uske
         asli source page se match karta hai.
      3. Source page ka `og:image` parhta hai (yahi filename scraper ne assets
         data mai record kiya tha) aur correct backend URL se image download
         karta hai.
      4. Image magic-bytes se validate karta hai (HTML ko image samajh kar
         upload nahi karta).
      5. Cloudinary par upload karta hai:
             qiststore/products/<category>/<slug>
         `overwrite: true` + `invalidate: true` ke saath, taake re-run safe ho.
      6. Un demo products ke liye jo fictitious hain (Nova X5, Roadster,
         Solar system etc.) ek clean branded 1200x1200 placeholder generate
         karta hai (sharp) aur Cloudinary par upload karta hai:
             qiststore/placeholders/<category>/<slug>
      7. `server/src/seed/product-images.ts` manifest likhta hai (61 products,
         Cloudinary secure URLs + publicId + alt + source page trace).
